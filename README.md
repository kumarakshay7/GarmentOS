# GarmentOS

GarmentOS is a garment retail shop management system for products, inventory, purchases, POS billing, customers, payments, invoices, returns, and reporting.

## Project structure

- `frontend/` - React + TypeScript web application
- `backend/` - FastAPI REST API
- `database/` - PostgreSQL schema and migrations
- `docs/` - product and technical documentation

## Development

The project is being built in small, testable modules. Never commit passwords, API keys, database credentials, or other secrets.
